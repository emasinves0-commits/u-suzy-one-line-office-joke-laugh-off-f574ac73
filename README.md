# One-Line Office Joke Laugh-Off

A tiny entry for the make.fun bounty "One-Line Office Joke Laugh-Off". `main.ts` writes a single joke line to `/output/entry.txt` (UTF-8, no trailing newline).

Run it with `node main.ts`. There is no build step and there are no dependencies.
